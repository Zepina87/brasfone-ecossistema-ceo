# Prefs, como gosto das coisas feitas

**Camada 2 de 4** | Carregada só quando o modo activo a exigir | Muda por mês

Este ficheiro é a diferença entre um agente que funciona e um agente que funciona **como tu
queres**. O `core` diz quem tu és. Este diz como trabalhas.

Cresce por acumulação. Cada vez que corriges o Cérebro e a correcção não é sobre factos mas sobre
forma, o sítio dela é aqui.
