# Ferramentas de ofício

Dezassete comandos que correm por cima de qualquer coisa. Não são agentes: não têm missão própria,
melhoram o que **tu** estás a fazer.

Instalam se com `./scripts/instalar.sh`.

## Gates de qualidade

Correm antes de algo sair. Ver `metodo/07-QUALIDADE.md`.

| Comando | Para quê |
|---|---|
| `/fact-check` | Números sem fonte, nomes não confirmados, capacidades que não existem |
| `/ghost-check` | Texto que soa a máquina, em português de Portugal |
| `/avoid-ai-writing` | O mesmo, em inglês. A versão original de onde o ghost-check derivou |
| `/taste` | Calibra o julgamento visual antes de gerar qualquer coisa que se veja |

## Design

| Comando | Para quê |
|---|---|
| `/impeccable` | O mais completo. Interfaces, hierarquia, tipografia, acessibilidade, detalhe |
| `/design-dna` | Extrai a identidade visual de um site ou imagem e devolve a aplicável |
| `/design-motion-principles` | Movimento e transições. Quando animar e quando não |
| `/frontend-design` | Gerar interface sem cair no aspecto genérico de IA |

## Memória

| Comando | Para quê |
|---|---|
| `/dream` | Consolida a memória a partir das conversas. Corre sozinho de tempo a tempo |
| `/learn` | Extrai o padrão de uma sessão em que resolveste algo não óbvio |

## Pensamento

| Comando | Para quê |
|---|---|
| `/grill-me` | Interroga te antes de construíres. Assunções, âmbito, casos de falha |
| `/adhd` | Divergência: muitas abordagens em paralelo quando não há caminho óbvio |
| `/deep-research` | Pesquisa em várias fases antes de afirmar. Não uma busca superficial |
| `/loop-engineering` | Desenhar uma rotina que corre sem ti à frente |
| `/skill-creator` | Criar e afinar comandos novos |

## Ambiente

| Comando | Para quê |
|---|---|
| `/strategic-compact` | Quando compactar a conversa, em fronteira de tarefa e não ao calhar |
| `/context-budget` | Onde está o desperdício de contexto na sessão |

---

## Proveniência

Alguns destes derivam de trabalho público com licença permissiva, adaptado para português de
Portugal e para este método. A atribuição está dentro de cada ficheiro e deve manter se.

Foram **sanitizados**: não têm chaves, caminhos de máquinas, dados de clientes nem referências a
sistemas que tu não tens. Se encontrares alguma, é um erro meu e quero saber.
