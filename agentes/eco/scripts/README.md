# Configuração local, não versionada

`entidades.json` e `entidades.json` (o de Wikidata, chamado `entidades.json` também na raiz do
agente) guardam dados da tua marca real: nome, domínio, concorrentes. Não são segredos, mas são
específicos do teu negócio, e este repositório é público.

Cria-os localmente a partir dos `.example.json`, e decide tu se algum dia os commitas. Por
omissão, mantém-nos fora do repositório: já vêm listados no `.gitignore` do agente.
